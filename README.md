# Portfolio-Management
In this project we study a theoretical portfolio consisting of six assets selected from the S&P 500 index and perform quantitative portfolio analysis in R Markdown.
The project begins with classical mean–variance portfolio theory and the Capital Asset Pricing Model (CAPM), including efficient frontier construction, market portfolios, and beta estimation. 
Later extensions of the project focus on additional portfolio and risk measures such as Value at Risk (VaR), volatility modelling, and option sensitivity parameters (Greeks).
